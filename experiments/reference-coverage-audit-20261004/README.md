# 参照点サンプリングの到達可能性監査（未採用）

保存済みWork7 V2の64参照を、画像や動画の正解を使わずに監査した。12点を等間隔で選ぶ処理により、元の適格alpha patch集合に存在した上下・左右領域が失われる参照が3件あった。さらに1件は元の集合にも上側領域がなく、既存の「上下3領域・左右2領域」の条件を満たせない。

`reference-coverage-selector.mjs`は元の12点を優先し、元集合にある領域を取り落とした場合だけ決定的に置換する隔離案。alpha適格条件、負例点の選び方、推論モデル、score・支持数・上下左右の判定条件を変更しない。元集合に存在しない領域は捏造しない。凍結済みソース・参照bankは保存したまま、別bankで比較する。

実参照では3件だけ変更、61件は維持。変更した3件の負例vectorは再計算後もbit一致。既存12枚のD1/D2と4枚のH4で同じ実Node/WASM providerを使って比較したところ、既存の枠は維持されたが、H4の敵不在710秒で主人公の誤枠が1件増えた。このため本番へ採用していない。

別途、上画面の同じ推定座標を持つ3通過から背景候補を作り、既知H4 570秒で鎌を含む身体を分離した。この背景補助と本案の組合せでは全身体の枠が得られたが、既知1例の診断であり、一般性能・種認識・全マップ対応・AT消費の証明ではない。背景の同一性・カメラ・遮蔽の条件、他場面の誤検知を検証する必要がある。

画像・ROM・動画・特徴vector・私的入力は同梱しない。本実験は既存のWeb経路からimportされない。
