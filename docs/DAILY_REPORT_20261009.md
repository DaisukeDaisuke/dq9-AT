# 開発日報 2026-10-09

## 目標と現状

目標は、ROMと動画から観測を積み重ね、マップ移動を跨いで長期的に現在ATを特定すること。DSTはデバッグ比較に限定し、本番推定に正解の内部メモリ状態を与えない。

現在ATは未特定。本番Webの実装は `5898d240` のままで、以下の新しい接続は未統合のソースとして保存した。

## メモリ常駐とログ

- ATの観測timeline/controllerを同じWorkerで保持し、短命の操作プロセスが終了しても、所有プロセスを維持したまま次の操作を受けられる入口を実装。
- メモリログの追記、行数、文字列検索、範囲読出しを確認。上限超過時は新しい追記全体を拒否し、既存ログは削除しない。
- 合成テストの8操作に加え、保存済み46観測とgapの全体hashが後続操作後も一致。46行のログも保持し、中間観測・ログファイルの自動生成は0件。
- 保持対象はAT観測と制御状態。DSエミュレータのCPU/RAM全体保持、実動画の連続総当たり、未保存状態の障害復旧は未達。

## 実29観測のAT接続

保存済み29観測を元の順序で既存controller/compiler/AT処理へ入力し、条件付きイベント13枝とACK13件を確認した。各枝の候補数は、それぞれの仮定の下で成立するイベント状態候補であり、枝同士の独立性や現在ATの回復を示さない。誤観測・no-event・未知の代替は維持した。

経路処理は31区間・330行へ接続したが、完成した経路chainは0。端点yawや元ソースのtarget仮定との不一致が残る。出生、イベント間の消費数、イベントから現在動画時点への消費を追加で推測していない。
