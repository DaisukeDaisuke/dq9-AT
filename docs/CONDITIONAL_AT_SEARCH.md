# 条件付きAT探索

`web/at-identify.html` は手入力の種・エンカウント表候補から、最後の種抽選直後の状態クラスを探す独立ページです。既存の ATPanel、ATSession、追跡画面のスタイルを変更しません。

## 操作

1. 観測行に表IDと種IDを10進数で入力します。名称付き入力候補が使えます。複数候補はカンマ区切り、空欄は不明です。表候補×種候補の全組み合わせを保持します。
2. 行順を抽選順と仮定する場合だけチェックします。各間隔は初期状態では不明です。有限範囲を入力する場合は最小・最大と根拠または仮定を明記します。消費数は次の抽選を含みます。
3. 全 low31 クラス、または根拠を記入した有限範囲を選び、計算予算を指定します。
4. 開始後は進捗・中止・再実行ができます。結果には探索済み／未探索の区間、別解、最大16候補とそれぞれの2つの32bit状態を表示します。JSON保存は補助機能です。

「合成例」は動作確認用であり、実測映像や実機のATを含みません。入力を変更した後も内容は利用者の仮説で、実測への昇格はありません。個人の入力や結果をサーバーへ送信する処理はありません。

## 結果の意味

- 各行を別の自然生成の種抽選と結び付けた、条件付きの枝を探索します。目視から出生を証明していません。
- 既存個体、再出現、認識違い、別生成経路などの未確定の枝を制約なしで保持します。網羅性は保証しません。
- 未知の抽選間隔に有限の上限を補いません。抽選から目視までの消費は未知のままで、現在映像の状態まで伝播しません。
- 2〜8イベントの完全な有限チェーンをフォームで作れます。バックエンドは最大32イベント、合計最大間隔256まで対応します。未対応の順序・間隔は未解決として保持します。
- 1イベントは解析的に集計します。複数イベントの検査予算とは別です。
- 有限の事前範囲の外側、予算停止・中止後の未探索部分は残ります。範囲内0件を全域棄却とは扱いません。
- low31クラスには2つの32bit状態があります。16件のサンプルを全候補集合とは扱いません。枝の件数を単純合計しません。
- 現在ATの確定、映像の自動モンスター識別、出生の自動認定、メタル移動ナビは接続していません。

## ビルドと配信

本番の `scripts/build.sh` は既存WASMをビルドした後、`scripts/build-at-identify.sh --verify` で同梱のレビュー済みカーネルのSHA-256とABIを確認し、実Workerテストとフォームテストを実行します。未知のコンパイラで識別カーネルを再生成しません。

- `web/wasm/at_identify.wasm`: 1826 bytes
- SHA-256: `a0279c9bd1c810af75640d3c7bba8ab5a65993c55c3dad53df9dc52cc23edb99`
- `wasm/at_identify.c` SHA-256: `f0d1c330d7a927b80789adf81f79a88152b6d886685844218ad647f38056f1d0`

再ビルドは emsdk 3.1.6 の upstream clang を明示します。

```sh
CLANG=/path/to/emsdk-3.1.6/upstream/bin/clang bash scripts/build-at-identify.sh
bash scripts/build-at-identify.sh --verify
node scripts/test-at-identify.mjs
node scripts/test-at-identify-page.mjs
node scripts/test-at-observation-compiler.mjs
```

別コンパイラのバイナリは同値性の再レビューが必要です。ハッシュガードを削除・緩和しないでください。ROM・保存状態・映像・抽出ゲームアセットはビルド入力でも配布物でもありません。公開済みの表データと既存 `at-core.mjs` を利用します。

## 検証範囲

- レビュー済みカーネルとブラウザ用Workerハンドラを使う実Node Workerで、進捗、中止、再実行、予算、ハッシュ不一致を検証
- 最小DOMハーネスでフォーム、エラー復帰、二重開始、読込中中止、実行中中止と再開、合成例、相対URLを検証
- コンパイラの公開表・合成テストと既存AT回帰を実行
- ブラウザの実画面・見た目・アクセシビリティの検証は別途必要。Nodeハーネスを実ブラウザ検証とは呼びません
